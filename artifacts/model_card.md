# RRR Wallet Behaviour Model V1

This model outputs **HIGH-RISK BEHAVIOUR PROBABILITY**, not criminality, guilt, or scammer status.

- Schema: RRRFeatureSchemaV1
- Decision threshold: 0.80
- Training split: time steps 1–34
- Validation split: time steps 35–41
- Test split: time steps 42–49
- Graph labels were not used as features.
- Feature importance is not causal interpretation.
